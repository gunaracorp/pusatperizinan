    66→## 1. Tentang Proyek
    67→
    68→**PusatPerizinan.com** adalah situs web produksi untuk jasa konsultan perizinan usaha Indonesia — bukan sekadar landing page, melainkan **mesin lead generation penuh** yang menggabungkan:
    69→
    70→| Dimensi | Isi |
    71→|---|---|
    72→| 🎯 **Bisnis** | Jasa pengurusan NIB, pendirian PT/CV/PMA, sertifikasi halal, izin BPOM/PIRT, PBG/SLF, AMDAL, izin umroh (PPIU/PPIH), IATA, MISA Arab Saudi, RKAB tambang, pajak & kepatuhan |
    73→| 📄 **Konten** | **10.706 URL** terindeks sitemap (13 seksi): 500 halaman layanan detail, 500 Katalog Premium PP-XXX, 36 KBLI, 15+ artikel blog, matriks industri, halaman biaya/syarat/perbandingan, 16 panduan + hub, 4 halaman dedikasi CTA (konsultasi/cek-izin/kalkulator/panduan) |
    74→| 🤖 **AI** | 5 tool AI aktif: Cek Izin AI, AI Consultant "RIZKI" 24/7, Cek Dokumen (vision), AI Roadmap 12 bulan, kalkulator pajak |
    75→| 🌍 **Internasional** | UI **30 bahasa** (termasuk RTL penuh: Arab, Farsi, Urdu, Ibrani) + `llms.txt` siap GEO/AI-search |
    76→| 💰 **Monetisasi** | Checkout otomatis (Midtrans/Tripay) dengan harga server-side anti-manipulasi + mode demo |
    77→| 🛠️ **Operasional** | Admin "Mission Control" untuk leads, orders, CMS blog, konsultasi, notifikasi |
    78→| 🚀 **Deploy** | 3 mode: dev (Turbopack), standalone (Node), **static export siap cPanel shared hosting** |
    79→
    80→### Mengapa proyek ini unik
    81→
    82→1. **500 halaman layanan programatik** dari satu dataset JSON (`src/data/layanan-500.json`) — masing-masing dengan metadata SEO unik, JSON-LD 4 tipe schema, harga kupon bertingkat, dan FAQ spesifik.
    83→2. **SEO-first sampai ke tulang**: sitemap index 12 seksi dengan `lastmod` deterministik, `robots.txt` GEO-ready, RSS feed, HTML sitemap di beranda, dan JSON-LD di hampir setiap halaman.
    84→3. **Bisa jalan di hosting shared murah**: pipeline build khusus meng-export seluruh situs jadi HTML murni (tanpa Node.js) — lengkap dengan panel download yang menjamin artefak **selalu versi terbaru**.

   145→## 3. Tech Stack
   146→
   147→| Lapisan | Teknologi | Catatan |
   148→|---|---|---|
   149→| Framework | **Next.js 16.1.3** (App Router, Turbopack) | `output: "standalone"`, opsi `output: "export"` via `BUILD_STATIC=1` |
   150→| Bahasa | **TypeScript 5** (strict) | `tsconfig` strict; path alias `@/*` → `src/*` |
   151→| UI | **React 19** + **Tailwind CSS 4** + **shadcn/ui** (New York, base neutral) | 48 komponen UI di `src/components/ui`; ikon **Lucide** |
   152→| Animasi | **framer-motion 12** + CSS compositor-only | `MotionProvider` global (`reducedMotion="user"`) |
   153→| Database | **Prisma 6.11** + **SQLite** (`db/custom.db`) | `prisma db push` alur utama |
   154→| State | Zustand (client) · TanStack Query (server state) | Terpasang, dipakai selektif |
   155→| Form | react-hook-form + zod 4 | Validasi dua sisi |
   156→| AI SDK | **z-ai-web-dev-sdk** | **WAJIB hanya di backend** (API routes) |
   157→| Payment SDK | Midtrans Snap · Tripay REST | Mode demo via `PAYMENT_DEMO_MODE` |
   158→| Lainnya | next-themes, sonner, embla-carousel, recharts, next-intl (pasif) | Lihat `package.json` (67 dependencies) |
   159→| Runtime | **Bun** (dev & tooling) | `bun run dev` di port **3000** |
   160→| Gateway | **Caddy** (`:81`) | Routing `XTransformPort` → layanan internal |

   308→
   309→### Tiga mode output (satu codebase)
   310→
   311→| Mode | Trigger | Output | Dipakai untuk |
   312→|---|---|---|---|
   313→| **Dev** | `bun run dev` | Standalone + Turbopack, HMR | Pengembangan sandbox (port 3000) |
   314→| **Standalone** | `bun run build` → `bun start` | `.next/standalone/server.js` (Node) | VPS / Passenger cPanel |
   315→| **Static Export** | `BUILD_STATIC=1 bun run build` (via `scripts/build-static.mjs`) | Folder `out/` — HTML+CSS+JS murni | **Shared hosting idwebhost (cPanel)** |
   316→
   317→Poin arsitektur penting:
   318→
   319→1. **Sitemap**: `next.config.ts` rewrite `/sitemap.xml → /api/sitemap-index` (hanya mode non-export — `output:"export"` tidak mendukung rewrites; mode statis mendapat `out/sitemap.xml` hasil post-proses build).
   320→2. **Patch sementara saat export**: `build-static.mjs` mem-patch 5 file route (`dynamicParams: false`) untuk memenuhi syarat literal statis Next.js, lalu **dipulihkan otomatis** di `finally` — source tree selalu kembali utuh.
   321→3. **Refactor permanen hasil export**: `/checkout` kini pre-renderable di semua mode (CheckoutFromQuery + Suspense); `/blog/[slug]` bebas-`cookies()` saat `BUILD_STATIC`.
   322→4. **Canonical host**: `https://pusatperizinan.com` (apex, HTTPS, tanpa www) — didefinisikan sekali di `src/lib/site.ts`, semua varian di-301.

   556→## 12. Design System & Motion
   557→
   558→### Prinsip (hasil audit design director — Task 6)
   559→
   560→1. **Compositor-only**: semua animasi hanya `transform` & `opacity` — nol layout shift, nol scroll listener, nol counter JS.
   561→2. **Signature easing**: `EASE = [0.22, 1, 0.36, 1]` · `STAGGER = 0.08`.
   562→3. **Reveal on scroll once**: `whileInView` + `viewport: { once: true, margin: "-64px" }` (jangan stagger `i*STAGGER` untuk grid panjang — pakai `i%3`).
   563→4. **WCAG 2.2 dua lapis**: `MotionProvider reducedMotion="user"` (framer) **+** media query CSS mematikan semua animasi CSS; `:focus-visible` outline emerald konsisten.
   564→

   658→- Ringkasan paket: ukuran + jumlah halaman + **badge mode** (LIGHT hijau / FULL) + **MD5** + waktu build WIB.
   659→- **Badge kesegaran**: `TERBARU` (< 24 jam, titik hijau) · `x hari lalu` · `>30 hari — pertimbangkan rebuild`.
   660→- Section "SEMUA FILE UNDUHAN (n)" dari `files[]` — ikon per jenis, ukuran, tanggal WIB, tombol unduh per-file.
   661→- Manifest di-fetch `cache: "no-store"` + cache-buster `?t=` — tidak pernah menampilkan data basi.
   662→

   664→
   665→| Mode | Isi | Tujuan |
   666→|---|---|---|
   667→| **LIGHT** (default) | Semua halaman inti + index semua direktori + 15 artikel blog + `/payment` & `/admin` digeser keluar; 12 folder long-tail (~9.500 hal) di-hold | Ringan untuk cPanel shared hosting |
   668→| **FULL** | Tanpa hold — ±9.500 halaman | Hosting yang sanggup |

   833→## 22. Troubleshooting — Pelajaran Lapangan
   834→
   835→Empat isu nyata yang pernah terjadi & solusi permanennya (jadi Anda tidak mengulanginya):
   836→
   837→| # | Gejala | Akar masalah | Solusi permanen |
   838→|---|---|---|---|
   839→| 1 | **Situs 500 SITEWIDE saat restart dingin** | `app/sitemap.xml/route.ts` = metadata route yang menormalkan segmen `[__metadata_id__]` → bentrok dengan `app/sitemap/[id]/route.ts` di posisi dinamis sama; ditambah sisa `app/sitemap.ts` lama | Hapus `sitemap.ts`; pindahkan handler index → `/api/sitemap-index` (route biasa); rewrite di `next.config.ts` **hanya non-export**. Pelajaran: *bug metadata-route hanya muncul di cold restart — selalu uji restart dingin* |
   840→| 2 | **Dev server mati mendadak (connection refused)** | OOM — dev + screenshot + sharp bersamaan | Restart OOM-safe: `NODE_OPTIONS="--max-old-space-size=2560" bun run dev > dev.log 2>&1 &` |
   841→| 3 | **Menu hilang di 1024–1280px** | Nav `hidden xl:flex` tetapi hamburger `lg:hidden` → keduanya absent di celah | Hamburger & mobile-menu `xl:hidden` (selaraskan dua breakpoint) |
   842→| 4 | **Preferensi bahasa hilang tiap reload** | `LanguageProvider` menulis `localStorage` **sebelum** deteksi preferensi (race) | Flag `ready` — tulis penyimpanan hanya setelah deteksi selesai |
   843→
   844→Bonus pitfall kecil yang sudah dimitigasi/dipahami:
   845→
   846→- Anchor relatif `#xxx` mati di non-beranda → selalu `/#xxx`.
   847→- `scrollWidth 391 vs 390` di mobile 390px = rounding piksel fraksional, **bukan** overflow nyata (uji dengan `scrollTo(80,0)` → `scrollX` tetap 0).
   848→- Klik toggle-close pada dropdown yang baru dibuka via hover → `openedByHover` ref.
   849→- Harga schema `"Rp 3,5jt"` pernah ter-parse jadi `35` → gunakan `priceToIdr()` dari `site.ts`.
   850→- `setState` sinkron di dalam `useEffect` akan kena aturan lint → pindah ke callback `setTimeout`.

   906→Dua jalur: (1) Admin → CMS → tulis + skor SEO live → PUBLISHED (tersimpan di tabel `Post`); (2) statis via `src/lib/blog-content.ts`. Bila slug sama, **DB menang**. Sitemap blog & RSS ikut otomatis.
