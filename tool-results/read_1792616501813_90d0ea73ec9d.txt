    82→## 1. Tentang Proyek
    83→
    84→**PusatPerizinan.com** adalah situs produksi jasa konsultan perizinan usaha Indonesia — bukan sekadar landing page, melainkan **mesin lead generation + e-commerce jasa + platform konten SEO** dalam satu codebase:
    85→
    86→| Dimensi | Isi |
    87→|---|---|
    88→| 🎯 **Bisnis** | NIB, pendirian PT/CV/PMA, sertifikasi halal, izin BPOM/PIRT, PBG/SLF, AMDAL, izin umroh (PPIU/PPIH), registrasi IATA, MISA Arab Saudi, RKAB tambang, pajak & kepatuhan |
    89→| 📄 **Konten** | **11.207 URL** terindeks (14 seksi sitemap): 500 halaman layanan v1, 500 Katalog Premium `PP-XXX`, 500 Katalog Pro `PP3-XXX`, 36 KBLI, blog, matriks industri, 16 panduan, 4 halaman dedikasi CTA, **KepatuhanPRO**, hub `/wilayah` |
    90→| 🛒 **E-commerce jasa** | Setiap layanan & langganan bisa **dibayar langsung**: `/checkout?paket=<kode>` — harga dikunci server-side (anti-manipulasi) |
    91→| 🤖 **AI** | 5 tool aktif: Cek Izin AI, Konsultan AI "RIZKI" 24/7, Cek Dokumen (vision), AI Roadmap 12 bulan, Kalkulator Pajak |
    92→| 🌍 **Internasional** | UI **30 bahasa** (RTL penuh: Arab, Farsi, Urdu, Ibrani) + `llms.txt` siap GEO/AI-search |
    93→| 💰 **Monetisasi** | Midtrans (Snap) · Tripay (QRIS/VA/e-wallet) · Mode Demo · KepatuhanPRO MRR (Rp 499rb–39,9jt) |
    94→| 🛠️ **Operasional** | Admin "Mission Control": leads, orders, CMS blog, konsultasi, notifikasi Telegram/WA |
    95→| 🚀 **Deploy** | 3 mode dari satu codebase: Dev (Turbopack) · Standalone (Node) · **Static Export siap cPanel shared hosting** |
    96→
    97→### Mengapa proyek ini unik
    98→
    99→1. **1.500 halaman layanan programatik** dari dataset terstruktur — masing-masing dengan metadata SEO unik, JSON-LD `Product/Offer/AggregateRating`, harga bertingkat, FAQ spesifik, dan **tombol beli langsung**.
   100→2. **SEO-first sampai ke tulang**: sitemap index 14 seksi dengan `lastmod` deterministik, `robots.txt` GEO-ready, RSS, HTML sitemap, JSON-LD di hampir setiap halaman, `llms.txt` + `llms-full.txt` untuk AI crawler.
   101→3. **Kontrak harga server-side**: harga *tidak pernah* dikirim dari client — `/api/payment/create` selalu menghitung dari `pricing.ts` / resolver katalog di server.
   102→4. **Bisa jalan di hosting shared murah**: pipeline export khusus menghasilkan HTML murni (tanpa Node.js), lengkap dengan panel download yang menjamin artefak selalu versi terbaru.

   160→## 3. Tech Stack / Teknologi
   161→
   162→| Lapisan | Teknologi | Catatan |
   163→|---|---|---|
   164→| Framework | **Next.js 16.1.3** (App Router, Turbopack) | `output: "standalone"`, opsi `output: "export"` via `BUILD_STATIC=1` |
   165→| Bahasa | **TypeScript 5** (strict) | Path alias `@/*` → `src/*` |
   166→| UI | **React 19** + **Tailwind CSS 4** + **shadcn/ui** (New York) | 48 komponen UI di `src/components/ui`; ikon **Lucide** |
   167→| Animasi | **framer-motion 12** + CSS compositor-only | `MotionProvider` global (`reducedMotion="user"`) |
   168→| Database | **Prisma 6.11** + **SQLite** (`db/custom.db`) | `prisma db push` alur utama |
   169→| State | Zustand (client) · TanStack Query (server state) | Terpasang, dipakai selektif |
   170→| Form | react-hook-form + zod 4 | Validasi dua sisi |
   171→| AI SDK | **z-ai-web-dev-sdk** | **WAJIB hanya di backend** (API routes) |
   172→| Payment SDK | Midtrans Snap · Tripay REST | Mode demo via `PAYMENT_DEMO_MODE` |
   173→| Runtime | **Bun** (dev & tooling) | `bun run dev` di port **3000** |
   174→| Gateway | **Caddy** (`:81`) | Routing `XTransformPort` → layanan internal |

   178→## 4. Quick Start / Mulai Cepat
   179→
   180→```bash
   181→# 1. Install dependency
   182→bun install
   183→
   184→# 2. Siapkan environment (daftar lengkap di §17)
   185→cat > .env <<'EOF'
   186→DATABASE_URL=file:./db/custom.db
   187→ADMIN_PASSWORD=<password-admin-anda>
   188→ADMIN_SECRET=<secret-acak-min-32-karakter>
   189→PAYMENT_DEMO_MODE=true
   190→EOF
   191→
   192→# 3. Push schema ke database
   193→bun run db:push
   194→
   195→# 4. Jalankan dev server (OOM-safe — lihat §20)
   196→NODE_OPTIONS="--max-old-space-size=2560" bun run dev > dev.log 2>&1 &
   197→
   198→# 5. Buka
   199→#    Situs → http://localhost:3000
   200→#    Admin → http://localhost:3000/admin
   201→#    Panel deploy → http://localhost:3000/?admin=1
   202→```
   203→
   204→> ⚠️ **Preview sandbox:** gunakan **Preview Panel** di kanan antarmuka (atau tombol *"Open in New Tab"*) — jangan `localhost` langsung.
   205→

   613→| 3 | **Menu hilang di 1024–1280px** | `hidden xl:flex` vs hamburger `lg:hidden` (celah breakpoint) | Samakan: keduanya `xl:hidden` |
   614→| 4 | **Preferensi bahasa hilang tiap reload** | `LanguageProvider` menulis storage sebelum deteksi (race) | Flag `ready` — tulis hanya setelah deteksi selesai |

   616→| 6 | **Overflow mobile 390px** | Button `whitespace-nowrap` memaksa min-content > track | `whitespace-normal leading-snug` di tombol submit |

   669→## 23. FAQ Developer
   670→
   671→<details>
   672→<summary><b>Kenapa harga tidak pernah dikirim dari client?</b></summary>
   673→<code>/api/payment/create</code> selalu menghitung dari <code>PACKAGES</code> (pricing.ts) atau <code>resolveAnyService()</code> (service-order.ts). Client hanya mengirim <b>kode</b>. Order menyimpan snapshot <code>amount</code> sendiri.
   674→</details>
   675→
   676→<details>
   677→<summary><b>Bagaimana menambah artikel blog baru?</b></summary>
   678→Dua jalur: Admin → CMS (tabel <code>Post</code>) atau statis via <code>blog-content.ts</code>. Bila slug sama, <b>DB menang</b>. Sitemap & RSS ikut otomatis.
   679→</details>
   680→
   681→<details>
   682→<summary><b>Bagaimana menambah bahasa ke-31?</b></summary>
   683→Entri di <code>i18n/languages.ts</code> + <code>LangCode</code> di <code>types.ts</code>, lalu isi key di 6 file <code>translations-*.ts</code>.
   684→</details>
   685→
   686→<details>
   687→<summary><b>Kenapa sitemap pakai rewrite, bukan app/sitemap.ts?</b></summary>
   688→<code>app/sitemap.ts</code> pernah bentrok segmen dinamis internal Next.js → 500 sitewide (§20 #1). Rewrite ke route handler valid di dev/standalone; mode export mendapat sitemap hasil post-proses.
   689→</details>
   690→
   691→<details>
   692→<summary><b>Boleh pakai SDK AI di component client?</b></summary>
   693→<b>Tidak.</b> <code>z-ai-web-dev-sdk</code> hanya di API routes (server). Client selalu fetch ke <code>/api/*</code>.
   694→</details>
   695→
   696→<details>
   697→<summary><b>Bagaimana menambah layanan baru ke Instant Order?</b></summary>
   698→Tambahkan ke dataset katalog yang relevan (v1/v2/v3) dengan kode & harga valid — resolver, checkout, dan halaman detail otomatis mengikuti. Untuk paket standar, tambahkan SKU di <code>pricing.ts</code>.
   699→</details>
   700→
   701→<details>
   702→<summary><b>Bagaimana rebuild paket hosting statis?</b></summary>
   703→<code>BUILD_STATIC=1 PACK_LIGHT=1 node scripts/build-static.mjs</code> lalu <code>node scripts/deploy-pack.mjs</code>. Verifikasi via <code>/?admin=1</code>: badge harus <code>TERBARU</code>.
   704→</details>

   791→### What makes it unique
   792→
   793→1. **1,500 programmatic service pages** from structured datasets — each with unique SEO metadata, `Product/Offer/AggregateRating` JSON-LD, tiered pricing, specific FAQs, and a **direct buy button**.

   971→
   972→### Macro data flow
   973→
   974→```mermaid
   975→flowchart LR
   976→    A["🧑‍💼 Visitor<br/>Landing · AI Tools · Catalog · Checkout"] --> B["⚡ Next.js API Routes<br/>/api/leads · /api/chat · /api/payment/* · /api/admin/*"]

   980→    C["🛒 Midtrans / Tripay"] --> B
   981→    F --> H["📈 Mission Control<br/>/admin (HMAC)"]

   984→### Three output modes (one codebase)
   985→
   986→| Mode | Trigger | Output | Used for |
   987→|---|---|---|---|
   988→| **Dev** | `bun run dev` | Turbopack + HMR | Sandbox development (port 3000) |
   989→| **Standalone** | `bun run build` → `bun start` | `.next/standalone/server.js` | VPS / cPanel Passenger |
   990→| **Static Export** | `BUILD_STATIC=1` + `scripts/build-static.mjs` | `out/` folder — pure HTML | **Shared hosting (cPanel)** |
   991→
   992→Key architecture points:
   993→
   994→1. **Sitemap**: `next.config.ts` rewrites `/sitemap.xml → /api/sitemap-index` (non-export only; static mode gets a post-processed `out/sitemap.xml`).
   995→2. **Temporary export patching**: `build-static.mjs` patches `dynamicParams: false` in 5 route files, then **auto-restores** them in `finally`.
   996→3. **Canonical host**: `https://pusatperizinan.com` (HTTPS apex) — defined once in `src/lib/site.ts`.
   997→4. **Price contract**: clients send **codes** (never numbers); the server computes prices via `pricing.ts` or `service-order.ts` → `resolveAnyService()`.

  1287→## 20. Troubleshooting — Field Lessons
  1288→
  1289→Real incidents that occurred & their permanent fixes:
  1290→
  1291→| # | Symptom | Root cause | Permanent fix |
  1292→|---|---|---|---|
  1293→| 1 | **Site-wide 500 on cold restart** | Sitemap metadata-route conflict (`[__metadata_id__]` vs `[id]`) + leftover `app/sitemap.ts` | Delete `sitemap.ts`; index → `/api/sitemap-index`; rewrite in `next.config.ts` non-export only |
  1294→| 2 | **Dev server dies suddenly (connection refused / only Z logo in preview)** | OOM or process killed between shell sessions | OOM-safe restart: `NODE_OPTIONS="--max-old-space-size=2560" bun run dev > dev.log 2>&1 &` |
  1295→| 3 | **Menu missing at 1024–1280px** | `hidden xl:flex` vs hamburger `lg:hidden` (breakpoint gap) | Align both to `xl:hidden` |
  1296→| 4 | **Language preference lost on reload** | `LanguageProvider` writes storage before detection (race) | `ready` flag — write only after detection completes |
  1297→| 5 | **Lead form 400 "invalid business type"** (6 pages) | `businessType`/`package` contract not sent as official values | Single-point fix in `lead-form.tsx`: SECTORS/PACKAGES whitelist |
  1298→| 6 | **Mobile 390px overflow** | `whitespace-nowrap` buttons force min-content > track | `whitespace-normal leading-snug` on submit buttons |
  1299→
  1300→Bonus pitfalls: relative `#xxx` anchors die on non-home pages → always `/#xxx` · `scrollWidth 391 vs 390` rounding is not real overflow · never hand-parse `"Rp 3,5jt"` → use `priceToIdr()` · synchronous `setState` inside `useEffect` → move to callback.

  1351→## 23. Developer FAQ
  1352→
  1353→<details>
  1354→<summary><b>Why are prices never sent from the client?</b></summary>
  1355→<code>/api/payment/create</code> always computes from <code>PACKAGES</code> (pricing.ts) or <code>resolveAnyService()</code> (service-order.ts). Clients only send a <b>code</b>. Orders store their own <code>amount</code> snapshot.
  1356→</details>
  1357→
  1358→<details>
  1359→<summary><b>How do I add a new blog article?</b></summary>
  1360→Two paths: Admin → CMS (<code>Post</code> table) or static via <code>blog-content.ts</code>. On slug collision, <b>DB wins</b>. Sitemap & RSS update automatically.
  1361→</details>
  1362→
  1363→<details>
  1364→<summary><b>How do I add a 31st language?</b></summary>
  1365→Add an entry in <code>i18n/languages.ts</code> + <code>LangCode</code> in <code>types.ts</code>, then fill keys in the 6 <code>translations-*.ts</code> files.
  1366→</details>
  1367→
  1368→<details>
  1369→<summary><b>Why does the sitemap use rewrites instead of app/sitemap.ts?</b></summary>
  1370→<code>app/sitemap.ts</code> once conflicted with Next.js internal dynamic segments → site-wide 500 (§20 #1). Rewrites to a route handler are valid in dev/standalone; export mode gets a post-processed sitemap.
  1371→</details>
  1372→
  1373→<details>
  1374→<summary><b>Can I use the AI SDK in client components?</b></summary>
  1375→<b>No.</b> <code>z-ai-web-dev-sdk</code> runs only in API routes (server). Clients always fetch <code>/api/*</code>.
  1376→</details>
  1377→
  1378→<details>
  1379→<summary><b>How do I add a new service to Instant Order?</b></summary>
  1380→Add it to the relevant catalog dataset (v1/v2/v3) with a valid code & price — the resolver, checkout, and detail pages adapt automatically. For standard packages, add a SKU in <code>pricing.ts</code>.
  1381→</details>
  1382→
  1383→<details>
  1384→<summary><b>How do I rebuild the static hosting pack?</b></summary>
  1385→<code>BUILD_STATIC=1 PACK_LIGHT=1 node scripts/build-static.mjs</code> then <code>node scripts/deploy-pack.mjs</code>. Verify via <code>/?admin=1</code>: badge must show <code>FRESH</code>.
  1386→</details>
